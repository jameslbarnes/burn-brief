# Security policy

burn/brief processes private group-chat data. Please do not paste message text,
phone numbers, database files or generated briefings into a public issue.

For a nonsensitive bug, open a GitHub issue with reproduction steps using
fictional data. If a report requires private material, first open an issue that
describes only the affected component and asks the maintainer for a private
contact channel.

The supported release is the latest commit on `main`. There are no packaged or
signed binaries yet; installations run from source through the user's agent.
